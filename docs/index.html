学习路径

由浅入深，配套源码运行。每个单元都是独立可读的。

  1. 环境准备：WSL2 + Docker + JDK 17 + Node 20
  2. 跑通后端：从 mvn spring-boot:run 到 Swagger 看到接口
  3. 跑通管理端：从 pnpm dev 到登录后台
  4. 跑通小程序：微信开发者工具导入 → 真机扫码
  5. 贯通业务流程：扫码 → 点餐 → 后厨 → 支付 → 报表

常见问题

这套教材适合谁？ 弱基础 / 想转全栈的 Java 后端学习者。零基础也能跟，但需要每行代码亲手敲一遍。
需要多少时间？ 通读约 8-12 小时，实战（跑通三端 + 调试 1 个订单流程）再加 6-10 小时。
跑不起来怎么办？ 看 Docker 部署指南 的 9 个排错清单，90% 的问题都在里面。
需要付费吗？ 完全免费 · MIT 协议 · 配套源码、文档、练习册全部公开。
